# Blockchain-Based IoT Security Research

**Role:** Research Assistant  
**Institution:** Manipal Institute of Technology  
**Duration:** Jul 2024 - Aug 2024

## Overview

This project focused on enhancing IoT device security using blockchain technology and machine learning. The goal was to create a robust, decentralized security framework that improves reliability and enforces access control for interconnected IoT devices.

## Key Technologies

- **Python** - Backend automation, blockchain interaction, and IoT data processing
- **Solidity** - Smart contract development and deployment
- **Ethereum Sepolia Testnet** - Blockchain testing and deployment
- **Web3.js / Web3.py** - Blockchain integration and communication
- **Elliptic Curve Cryptography (ECC)** - Strong encryption for IoT devices
- **Attribute-Based Access Control (ABAC)** - Secure access management
- **Machine Learning** - Replaced traditional Zero Trust Architecture for lightweight security evaluation

## Accomplishments

- Increased research reliability by **10%** by designing a blockchain-based IoT security solution.
- Developed and deployed Solidity smart contracts on the Ethereum Sepolia testnet to securely manage device interactions.
- Secured three interconnected IoT devices using ECC and an ABAC system integrated with blockchain.
- Spearheaded a machine learning-based security solution by defining lightweight interval criteria to replace traditional Zero Trust Architecture.

## My Contributions

- Designed and implemented the backend in Python, automating IoT data processing and blockchain interactions.
- Developed smart contracts in Solidity and deployed them on the Ethereum testnet.
- Integrated cryptographic algorithms (ECC) and access control policies into IoT devices.
- Collaborated on integrating a machine learning model to improve security decision-making.

## Outcome

- Successfully demonstrated a secure, decentralized IoT system with enhanced reliability.
- Provided a research-backed approach to blockchain-enabled IoT security and lightweight, AI-driven access control.
